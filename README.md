# Rick and Morty Explorer

Aplicación web de una sola página (SPA) que consume la API pública de Rick and Morty. Permite explorar personajes usando tarjetas, búsqueda, filtros y paginación.

## Integrantes
- Nombre del alumno 1
- Nombre del alumno 2 (opcional)

## Tecnologías utilizadas
- HTML5 semántico
- CSS en archivo separado
- JavaScript moderno (ES Modules, fetch, async/await)

## Cómo ejecutar el proyecto
1. Abrir `index.html` en un navegador moderno.
2. O usar un servidor local simple si se desea (por ejemplo Live Server de VS Code).

## Funcionalidades
- Listado de personajes en tarjetas.
- Paginación con botones "Anterior" y "Siguiente".
- Indicador de estado con color: verde (Alive), rojo (Dead), gris (unknown).
- Búsqueda por nombre.
- Filtros por estado, género y especie.
- Diseño responsivo para escritorio y celular.

## API utilizada
- Rick and Morty API: https://rickandmortyapi.com/
